# MessagerieChiffre 

Une startup souhaite déployer un outil de messagerie interne sécurisée pour ses équipes. Les messages échangés ne doivent en aucun cas être lisibles par un tiers, même si le trafic réseau 
est intercepté. Votre mission est de concevoir et implémenter, from scratch, un système de 
chat en temps réel en Python dans lequel chaque message est chiffré côté expéditeur, 
transmis sur le réseau, puis déchiffré côté destinataire. 
Ce projet mobilise les compétences vues en cours : algorithmes de chiffrement symétrique et 
asymétrique, échange de clés, hachage, et communication réseau par sockets.
